# What is AUSTRO Studio AI?

AUSTRO Studio AI is an AI-powered Content Operating System designed to automate the entire content production workflow.

It uses specialized AI Agents working together as a professional production team.

The platform is not a simple AI chatbot.

It is an intelligent operating system capable of planning, researching, creating, editing, reviewing, publishing, analyzing and continuously improving digital content.
